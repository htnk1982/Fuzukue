# 文机（ふづくえ） / Fuzukue

**文字数×行数の版面に文章を流し込み、罫線を引いて、印刷して終わる。ワープロ専用機の良さを現代のWindowsで再構成した日本語ワープロです。**

文机は、紙面にテキストボックスを配置するのではなく、**1文字1マスの版面を直接編集する**文書作成ソフトです。文章、見出し、箇条書き、罫線、表、図を同じ紙面の中で扱い、印刷結果を意識しながら書き進められます。

> **バージョン：** `1.0.10c.1-alpha`  
> **対応OS：** Windows 10 / 11  
> **起動方法：** Edge・Chromeのアプリモード／任意で単体Windows実行ファイルをビルド

## 設計思想

- **1画面・無モーダル。** 文書を中心に据え、操作は上部の帯と下部の状態行に集約。ダイアログやプルダウンで編集を中断させません。取説やアウトラインは右側パネルに表示します。
- **文字数×行数で組む。** 用紙、1行の文字数、1ページの行数、字下げ、行の位置、改ページを指定し、文字を版面へ流し込みます。
- **白黒＋網点の印刷イメージ。** 文字の強弱や罫線、網掛け、見出し飾りまで、印刷時の見た目を意識した表示に統一します。
- **キーボード中心の操作。** F1～F10の機能グループと、画面に表示される1文字のコマンドで操作できます。クリックにも対応します。
- **中身を読める原本。** 独自形式`.fzk`はUTF-8テキストです。文書構造や書式を日本語の指示で保存し、生成AIにも読み込ませられます。

## 主な機能

### 文章と構造の編集

- 表題、数字見出し、記号見出し、箇条書き、番号付き箇条書き。階層別の番号・記号体系をカスタマイズできます。
- 太字、下線、傍点、網掛け、白抜き、取消線、倍角、リンクなどの文字装飾。
- アウトライン、検索・置換、自動目次、柱（ヘッダー・フッター）、ページ番号。
- 元に戻す・やり直す、自動保存、復旧用データ、直近の版の履歴。

### 紙面と図表

- キーボード・マウスでの罫線描画、囲み、区切り線、新聞的な見出し飾り。
- 表の挿入と様式変更。格子、新聞、統計表、決算表などのスタイルを用意。
- 画像の挿入、図番号の参照、箱と矢印で作るフローチャート。MarkdownのMermaid形式との往復にも対応。
- A4横を基本とする**資料書式**。本文欄と図表欄を分けた説明資料を作成できます。

### ファイル形式

| 形式 | 対応内容 |
| --- | --- |
| `.fzk` | 独自の原本形式。UTF-8テキストで文書構造や固有の書式を保持 |
| `.md`（GFM） | 読み込み・貼り付け・書き出し。見出し、箇条書き、表、コード、リンク、対応するMermaid図など |
| `.txt` | テキストの読み込み・書き出し |
| `.docx` | 見出し、番号、表、文字装飾などをWord文書へ書き出し |
| `.pptx` | 資料書式を含め、PowerPointへ書き出し |
| PDF・紙 | 印刷画面から出力。「PDFとして保存」を選べばPDFを作成 |

**形式について：** 文机固有の紙面設定や装飾を保持する原本は`.fzk`です。Markdownは他のツールや生成AIと文書構造を受け渡すのに向きますが、文机固有の書式すべてを再現できるわけではありません。

## 起動方法（インストール不要）

1. 配布ZIPを任意のフォルダに展開します。日本語や空白を含むパスでも構いません。
2. **`文机を起動.bat`** をダブルクリックします。
3. Microsoft Edge（なければChrome）のアプリモードで、白紙の文書が開きます。
4. そのまま入力できます。操作方法は**F1**、コマンド検索は**Ctrl+K**です。
5. **Ctrl+S**で`.fzk`原本を保存し、**Ctrl+P**で印刷・PDF保存します。

書体はPCにインストール済みのものを利用します。既定は**BIZ UD明朝／BIZ UDゴシック**（なければ他の書体に代替）で、**F9 → F**から変更できます。ランタイムや書体を配布物に同梱する方式ではありません。

## 主な操作キー

| キー | 機能 |
| --- | --- |
| **F1** | 取扱説明書 |
| **F2** | ファイルの新規作成・保存・印刷・書き出し |
| **F3** | 編集・元に戻す・検索・置換 |
| **F4** | 文字の装飾 |
| **F5** | 段落・見出し・箇条書き |
| **F6** | 配置・字下げ・改ページ |
| **F7** | 表・画像・図・目次などの挿入 |
| **F8** | 罫線・網掛け・見出し飾り |
| **F9** | 用紙・版面・書体などの書式 |
| **F10** | 表示・倍率・アウトライン・コマンド一覧 |
| **Ctrl+S** | 保存 |
| **Ctrl+P** | 印刷・PDF保存 |
| **Ctrl+K** | コマンド検索 |
| **Ctrl+Shift+O** | アウトラインの開閉 |

たとえば**F5**を押すと段落グループが選ばれ、画面に表示された1文字のキーで操作できます。**Esc**で「構え」を解除します。メニューのタイルはマウスからも操作できます。

## 単体exeを作る場合（任意）

Go製ホストから、アプリを1つのWindows実行ファイルへまとめることもできます。

1. 事前にGoをインストールします（例：`winget install GoLang.Go`）。
2. **`host/build-windows.bat`** を実行します。
3. 1つ上のフォルダに**`Fuzukue.exe`**が作られます（添付資料上は約10MB）。

詳細は**`host/README.md`**を参照してください。exe版では、配布物にある**`文机を関連付け（exe版）.bat`**から`.fzk`ファイルの関連付けも可能です。

## 見本・取扱説明書

配布物の**`samples/`**には、見本の`.fzk`文書、Markdownの見本、取扱説明書を文書化した**`取扱説明書.fzk`**が用意されています。Markdownの実装上の対応方針は**`GFM対応設計.md`**を参照してください。

## 現時点での対象範囲

文机は**横書き・1文字1マスの組版**を基本とします。縦組み、写真への文字の回り込み、新聞の段間罫などは設計上取り込んでいません。また、Word・PowerPointへの書き出しでは、文机の印刷イメージと完全には一致しない要素があります。

現在は**アルファ版**です。重要な文書は別途バックアップを取り、外部へ渡す書き出しファイルは内容とレイアウトを確認してください。
